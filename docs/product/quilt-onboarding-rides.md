# Thread / Quilt Onboarding Rides

Product theme catalog adopted 2026-09-12. These six themes complement the
[three 22-minute discovery tutorials](../quilt-discovery-tutorials.md); those three
remain the first implementation and timed acceptance scope.

## Relationship to the first build

| Theme | Existing discovery loop to personalize | Tangible result |
| --- | --- | --- |
| After Work Rescue | Messy idea → starter plan | After Work Rescue Kit |
| Healthy Low-Energy Eating | Messy idea → starter plan; golden thread → reusable memory | Healthy Low-Energy Food Plan |
| Smart Savings for My Goals | Compare → decision card | My Good Deals Map |
| Get My Spark Back | Golden thread → memory card | My Spark Patch |
| Protect My Bigger Dream | Messy idea → starter plan; golden thread → re-entry context | My Ambitious Goal Thread |
| Happiest Me | Messy scraps → a named Thread of chosen context | Happiest Me Library |

The mapping is an implementation-planning interpretation, not a claim that all six
themes have been built or tested. Each ride should produce one focused `%thread` whose Pins hold the
saved material and whose editable Thread prompt can state the standing purpose or opening guidance.
A broader `#quilt` Quilt may group several related Threads; it is not the direct home of individual Pins.
Use a small, personalized path with payoff by
minute 7 and a saved result by minute 22. Do not require all six rides, an extensive
questionnaire, or a finished personal profile before first value. A user can leave
and return to their retained work without starting over.

For the first build, a useful result must come from the existing Pin/Thread/snapshot/source/stitch
loop. Live deal watches, background preparation, image-library conveniences,
and scheduled postcards need separately scoped implementation and availability
checks. A saved preference or watch idea is not an active monitor.

These rides teach Threads and Quilts through relief and usefulness, not through feature explanation.

The user should feel the benefit first, then understand that the Thread kept the useful details and a
Quilt can keep related Threads together.

## Ride 1: After Work Rescue

### Goal
Help a tired user arrive home and avoid crashing into evening chaos.

### User need
“I’m exhausted and I still need to eat, prepare for tomorrow, and not lose the thread.”

### Eve helps create

- low-energy dinner options
- fallback healthy meals
- evening reset ideas
- “what matters tonight”
- “what can wait”

### Thread output
`After Work Rescue Kit`

### Teaches

- Eve remembers low-energy needs
- a Thread can preserve practical support
- Eve can reduce evening decision fatigue

## Ride 6: Happiest Me

### Goal
Create an emotionally rich, aesthetic, identity-centered profile of the user at their happiest.

### Eve helps create

- a library of images, moods, colors, places, routines, people, and symbols
- what the user looks like when they feel most alive
- what they care about most
- which aesthetics and emotional atmospheres feel like “home”
- what kinds of mornings, celebrations, and support feel most nourishing

### Thread output
`Happiest Me Library`

### Teaches

- Eve can feel more human and personally attuned
- a Thread can preserve aesthetic and emotional context
- this library can later be used for postcards and caring, personalized touches

## Onboarding principle

Do not lead onboarding with storage taxonomy. Teach the Thread first as:

- “I saved this so you don’t have to hold it alone.”
- “This will still be here later.”
- “Future you now has a way back in.”

Then teach a Quilt only when the user has related Threads to group: “These belong together, so you
can bring the wider context back without mixing every Pin into one Thread.”

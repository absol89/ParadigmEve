## Copy

I think “use AI to save time” can become another task someone has to manage. I'd start by asking whether it removes one *complete* annoying step, not how many tools it uses.

For example, give it one boring, low-risk job: organize a messy set of options and return only the two decisions that still need your judgment. If setting it up and checking the answer takes longer than doing the thing, it didn't help.

It's also reasonable to say no to sharing sensitive household or work data. Practical usefulness matters more than the AI label.

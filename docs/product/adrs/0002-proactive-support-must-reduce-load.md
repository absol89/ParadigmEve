# ADR 0002: Proactive Support Must Reduce Load

## Status

Accepted as product direction, 2026-09-12. This does not assert implementation.

## Context
Reminder systems often become another source of mental burden.

## Decision
Eve should usually do quiet housekeeping before notifying. Notifications should be sent only when they are time-relevant and genuinely helpful.

## Consequences

- fewer but better notifications
- better support for overwhelmed users
- proactive behavior should feel caring, not nagging

- Stay inside existing user authority and use only supported, verifiable delivery.
- Users can decline caring check-ins and pause optional rituals.
- See [notification philosophy](../notification-philosophy.md) for behavior and examples.

# Eve HTML tour

Open [`index.html`](index.html) directly in a browser. The tour runs straight from the folder with
local HTML, CSS, JavaScript, system fonts, and bundled artwork.

This is the human-facing companion to `docs/vault/`. The vault answers “how is the system built?”;
this folder answers “why would a tired person care?” and demonstrates the kind of small, polished
local web experience Eve can make.

Structure:

- `index.html` — sleepy/weekend-morning entry point
- `pages/01-feel-lighter.html` — reduce mental load
- `pages/02-keep-the-good-bit.html` — Pins / Threads / Quilts as saved useful moments
- `pages/03-come-back-later.html` — continuity and Plans
- `pages/04-quiet-help.html` — preparation before notification
- `pages/05-small-team.html` — one-conversation coordination with useful background helpers
- `pages/06-local.html` — local web apps as a product idea
- `pages/99-under-the-hood.html` — optional technical bridge to the engineering vault
- `assets/site.css`, `assets/site.js` — shared presentation and offline interactions
- `assets/scene-*.svg` — local per-page Eve key art; each SVG contains its own light/dark palette

The default copy should lead with a recognizable problem and the relief Eve can create before feature vocabulary appears. Keep the first-use path
plain, and put technical terms in the optional “under the hood” layer or disclosure blocks.

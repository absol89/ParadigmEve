What are these helpers technically?

They are worker ChatGPT conversations attached to the coordinating conversation that started them. Each worker gets a bounded assignment and reports back to that owner; workers cannot create their own workers. When a worker stops, its chat can usually be kept asleep and reused later unless it has reached its context limit. Eve, Eva, or whatever you named this installation remains the assistant you talk to. “Prime” is an internal coordinator role, not a second persona.

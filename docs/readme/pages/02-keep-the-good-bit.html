How do Pins, Threads, and Quilts fit together?

A Pin is one saved message, result, or Plan, and it must belong to exactly one Thread. Threads are the specific places where related Pins live; Quilts are wider groupings that can contain multiple Threads and use `#` references such as #Eve. Source links use recorded session and event identity, so missing provenance stays missing instead of being guessed.

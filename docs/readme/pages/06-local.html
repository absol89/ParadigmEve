A folder can hold the whole tool

Keep the tool as small as the job.

A household dashboard. A garden planner. A visual recipe book. A renovation tracker. A family archive. A project dashboard. A decision helper. A useful version can be a handful of files built around one specific job, with the labels and information that job actually needs.

Give each tool a clear home and a clear boundary.

Eve can work in a local project folder you select. The project gives that chat a working folder; it does not grant new access. File tools still check the folders you approved. Command execution, when enabled, is broader and is controlled separately.

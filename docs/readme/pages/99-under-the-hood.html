Okay. How does Eve actually do this?

The short version: ChatGPT still runs the model. ParadigmEve records the local session and its history, can use local tools you authorize, and keeps the project and queued work attached when the browser conversation changes.

Keep the chat habit you already know

The model still runs in ChatGPT. ParadigmEve records the conversation and local tool activity around it so the work has a durable local history.

Your computer does local work

Files, shell commands, and desktop actions cross ParadigmEve’s explicit local permission boundaries. Selected plugins keep their own service or operating-system permissions.

The Companion keeps browser identity clear

The browser extension carries exact conversation, turn, and request evidence so local work is attributed to the right chat instead of guessed from whichever tab looks active.

Keeping the same work

A chat can change while the work stays together.

Eve keeps a durable local session. When a ChatGPT conversation gets too long, Compact & Resume can rebind that same session from conversation A to B while the project, recorded history, Plans, queued work, and worker family stay attached.

Keeping facts clear

Saved context and live source links are different facts.

A Pin saves a useful item into a Thread with its recorded source identity and bounded nearby context when available. Whether the original source can still be opened is tracked separately, so a saved copy does not silently become a guessed live link.

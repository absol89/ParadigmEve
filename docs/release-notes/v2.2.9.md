# ParadigmEve 2.2.9 — Clearer Windows downloads

## 2.2.9

2.2.9 starts the move from `Setup` to the clearer `Windows` name for Windows installers while keeping
automatic updates compatible with existing installations. Bridge protocol **15** is unchanged.

### Changed

- 2.2.9 still publishes `ParadigmEve-Setup-x64-debug.exe` and `ParadigmEve-Setup-arm64-debug.exe`, so
  2.2.8 and older installations can update into it using the filename they already know.
- The 2.2.9 updater also accepts `ParadigmEve-Windows-…` for the same architecture and build flavor, and
  prefers that name when both are checksum-authorized. That prepares 2.3.0 to switch the public filename.
- Public macOS releases attach DMGs only. The ZIPs may still be built and tested in CI, but they are no longer
  duplicate public installation assets. The public `SHA256SUMS.txt` lists only the attached assets; the CI
  candidate still checksums and verifies the ZIPs before they are left out.

### Cross-platform release contract

The public workflow still targets Windows x64/arm64, macOS x64/arm64, and Linux x64/arm64. macOS 13
Ventura or newer remains the supported floor. Current macOS artifacts are **unsigned** and
**unnotarized** development/release-build outputs unless a later publishing process establishes signing
and notarization.

Linux keeps the documented static sandbox fallback for hosts where unprivileged user namespaces are
unavailable. The explicit `--no-sandbox` escape hatch remains a last-resort compatibility path for those
hosts, not the default launch mode.

Published builds are the debug flavor for now. The 2.2.9 workflow artifact names are:

- `ParadigmEve-Setup-x64-debug.exe`
- `ParadigmEve-Setup-arm64-debug.exe`
- `ParadigmEve-macOS-x64-debug.dmg`
- `ParadigmEve-macOS-arm64-debug.dmg`
- `ParadigmEve-Linux-x64-debug.AppImage`
- `ParadigmEve-Linux-x64-debug.deb`
- `ParadigmEve-Linux-arm64-debug.AppImage`
- `ParadigmEve-Linux-arm64-debug.deb`
- `ParadigmEve-Extension.zip`
- `ParadigmEve-Native-Sources.tar.gz`
- `SHA256SUMS.txt`

### Release boundary

This source line prepares the 2.2.9 compatibility bridge only. Tagging, publishing, and promoting a release
to GitHub Latest remain separate explicit release actions.

## Candidate 1

Status: source candidate prepared from the published 2.4.5 release checkpoint. Not yet installed or publicly released.

### Prime / Twin model integrity

- Established chats now persist the model + reasoning pair explicitly chosen in Eve's composer as session-local intent.
- New Chat remains the only owner of the global default for later new chats.
- Prime and Twin therefore no longer borrow each other's provisional model/reasoning choice after an app restart when provider proof is temporarily unavailable.
- A newer durable session preference replaces stale renderer-only cache.
- Compact & Resume keeps the durable session preference while rejecting a selectedModel observation whose ChatGPT conversation id belongs to the old frontend.
- Exact current-provider observations remain stronger evidence when they arrive.

### %eveal and local Ollama tool reliability

- Adds the packaged, read-only EVE-Al Quick reveal at /paradigmeve-eveal and a starter %eveal Thread.
- The suite ships contestant material only. Hidden reviewer keys/scoring material are not part of the packaged suite.
- Local Ollama chat now uses the daemon's native /api/chat route so Eve can explicitly request a context window large enough for the system prompt, activated %Thread context, and tool schemas.
- Local context windows grow in bounded steps, respect the model-reported maximum when available, and do not shrink during the process lifetime to avoid unnecessary model reloads.
- Ollama-native tool arguments may arrive as objects and are handled without forcing OpenAI-compatible JSON-string formatting.
- A %Thread activated by the opening local-chat message is retained in that chat's system context on later turns rather than disappearing when old history is trimmed.
- %eveal opening context tells a local model where the suite is and preserves its read-only boundary; remote routes without file tools are told that the run cannot proceed instead of pretending to execute it.

### Read-only Twin review follow-ups

- One-shot Ollama workers still use the OpenAI-compatible transport; c1's native /api/chat context-window fix applies to local chat sessions.
- Ollama model context discovery through /api/show does not yet carry the turn's abort signal or a timeout. Cancellation latency under a stalled discovery request remains unverified.

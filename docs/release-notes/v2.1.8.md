# ParadigmEve private dogfood release candidate

## 2.1.8

Integrated Windows debug checkpoint for Compact & Resume continuity hardening and the final 2.1.8 Pins/Threads/Quilts source-navigation fixes.

## Why this build exists

A real 2.1.7 automatic compaction from conversation `6a000002-0000-83ed-8000-000000000002` created the marked successor URL `https://chatgpt.com/?clf=90daf7181b53733f#clf=90daf7181b53733f`, but the successor never redeemed its local ParadigmEve command. Durable continuation state showed the source handoff was saved and sent, while `claimedBy`, destination conversation id and destination Send all remained empty/not-attempted.

The browser's failure text came from older Companion runtime logic even though the refreshed extension files on disk already contained the newer same-tab recovery path. Chrome had kept an older MV3 service worker resident. 2.1.8 therefore treats live Companion generation as part of the continuity contract rather than trusting on-disk bytes alone.

The separate ChatGPT request to `/backend-api/f/conversation/resume` that can return HTTP 405 is provider-owned. ParadigmEve's A→B continuation uses its authenticated loopback `POST /commands/redeem` and `/commands/ack` flow and must not depend on that private provider endpoint.

## What changed

- Bridge protocol is **15**. A stale protocol-14 Companion, including one with the same app version label, is incompatible and cannot receive browser placement authority.
- A newly created exact marked successor that never redeems receives at most one same-tab reload. A changed marker/route or an explicit page safety veto fails closed instead of overwriting user state, and recovery never creates a duplicate successor tab.
- Fresh destination redeem replies are retried idempotently when the bridge accepted the command but Chrome loses only the service-worker-to-page reply.
- Debug dogfood compacts earlier: **300,000** advisory/automatic threshold and **400,000** limit. Dev and shipping remain **369,000 / 492,000**. Only exact untouched old defaults migrate; user-tuned values remain exact.
- `scripts/verify-continuity-acceptance.mjs` is the focused regression gate for this failure family. It also rejects any production dependency on ChatGPT's private `/backend-api/f/conversation/resume` route.
- Pin source navigation now uses exact durable `sessionId + eventSeq` provenance. Same-session and historical cross-session sources load the page containing that exact event, switch to Timeline, clear stale filters, reveal collapsed groups, center the row and briefly highlight it.
- A historical-navigation ownership guard prevents background session/detail refresh from overwriting the requested page while the first historical page is arriving. This closes the live race that previously opened the correct old session but landed near its newer tail.
- Thread detail now supports direct **Unpin** and explicit **Delete Thread**. Unpin removes only the Pin. Deleting a Thread removes that Thread plus its owned Pins atomically while preserving broader Quilts; an empty Thread remains until explicitly deleted.

## ParadigmEve private dogfood build

## 2.1.2

- **Bring the installer, not the repo.** The Windows installer carries the runtime pieces ParadigmEve itself needs, so a gaming PC does not need the ParadigmEve source tree, Node, Git, Python or uv just to run Eve/Eva.
- **Eve on one computer, Eva on another.** Each installation can choose its own primary connector name. The name appears in tunnel and ChatGPT app setup, connector guidance and model-facing work context, while the stable ParadigmEve product/Companion identity stays unchanged. Separate computers should still use separate tunnels (and preferably separate restricted Tunnels Read + Use keys) and separate active ChatGPT conversations.
- **English or Swedish UI.** Setup and Settings use one compact current-language selector: the visible flag follows the selected locale, and the dropdown currently offers US English and Swedish without turning the header into a row of flags. The control is ready to grow to more locales later. User-authored chat text is never rewritten, and Unicode connection names such as Eva Å remain supported.
- **Friendlier first run.** The current startup splash, browser guide and homey Pins/Plans visual pass are included in this dogfood build, together with the simpler workspace navigation being tested in the 2.1.x cycle.
- **Completed checklists stay readable.** Finished items keep their checkmark and use only a gentle text dimming—no strikethrough—in the browser guide, the Plans library and the inline chat plan.

The native source download accompanies packaged builds and is covered by the release checksums. Installed legal notices retain the upstream Chat On Steroids contributor copyright and third-party license texts required by the bundled code.

> **macOS:** publisher-unsigned and unnotarized; verify the checksum. Requires macOS 13 Ventura or newer. Ad-hoc sealing provides bundle integrity, not publisher trust.
> **Linux:** prefer the DEB on Debian/Ubuntu. Where unprivileged user namespaces are disabled, the AppImage launcher can fall back to `--no-sandbox`.

This branch is intended for private/local dogfooding. Do not publish it through the upstream public release workflow.

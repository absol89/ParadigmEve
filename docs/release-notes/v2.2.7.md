# ParadigmEve 2.2.7 — First GitHub-published debug pre-release

## 2.2.7

2.2.7 is cumulative over 2.2.6 and keeps bridge protocol **15**. It is the first release built and
published by the GitHub workflow as a **debug pre-release**, and the first one a 2.2.6 installation can
update to by itself once it is promoted to Latest.

### Changed

- The bundled OpenAI `tunnel-client` moves from v0.0.14 to **v0.0.15**, pinned by the SHA-256 of each of
  the six platform archives as published in OpenAI's `SHA256SUMS.txt`.

### Update path acceptance

This release stays a pre-release until it is vetted. Promoting it to **Latest** on
`absol89/ParadigmEve` is what offers it to Windows x64 debug installations of 2.2.6: within six hours
they download `ParadigmEve-Setup-x64-debug.exe`, check it against this release's `SHA256SUMS.txt`, and
show **Install now**. Confirm that on a 2.2.6 install before relying on it.

### Cross-platform release contract

The public workflow still targets Windows x64/arm64, macOS x64/arm64, and Linux x64/arm64. macOS 13
Ventura or newer is the supported floor. Current macOS artifacts are **unsigned** and
**unnotarized** development/release-build outputs unless a later publishing process explicitly
establishes signing and notarization.

Linux keeps the documented static sandbox fallback for hosts where unprivileged user namespaces are
unavailable. The explicit `--no-sandbox` escape hatch is a last-resort compatibility path for those
hosts, not the default launch mode.

Published builds are the **debug** flavor for now, and every release is created as a GitHub
pre-release. The reviewed public workflow artifact names are:

- `ParadigmEve-Setup-x64-debug.exe`
- `ParadigmEve-Setup-arm64-debug.exe`
- `ParadigmEve-macOS-x64-debug.dmg`
- `ParadigmEve-macOS-x64-debug.zip`
- `ParadigmEve-macOS-arm64-debug.dmg`
- `ParadigmEve-macOS-arm64-debug.zip`
- `ParadigmEve-Linux-x64-debug.AppImage`
- `ParadigmEve-Linux-x64-debug.deb`
- `ParadigmEve-Linux-arm64-debug.AppImage`
- `ParadigmEve-Linux-arm64-debug.deb`
- `ParadigmEve-Extension.zip`
- `ParadigmEve-Native-Sources.tar.gz`
- `SHA256SUMS.txt`


### Release boundary

This document makes the 2.2.7 source/version surface reviewable; publishing happens only through
`publish.yml` dispatched at the `v2.2.7` tag, which creates a pre-release.

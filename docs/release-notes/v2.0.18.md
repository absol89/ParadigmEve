## ParadigmEve private build

## 2.0.18

- Everyday browser recovery is now part of normal Eve use rather than Guided Setup. The View menu and status action can Open, Show or Restore Eve Browser while preserving the exact dedicated ParadigmEve Chrome profile.
- Closing the whole Eve Browser or only its final ChatGPT tab is recoverable without rerunning onboarding. Repeated recovery requests are coalesced, an already-owned browser window is reused, and exact ChatGPT-tab evidence is kept separate from the Companion's broader 60-second presence clock.
- A failed Chrome tab census is treated as unknown rather than “zero tabs,” so transient browser-query failures do not manufacture absence and open an unnecessary duplicate ChatGPT tab.
- Onboarding completion is durable once the first real end-to-end ChatGPT request has verified every required surface. Fresh installs still require that verification; completed users and legacy upgrades are not sent back to Setup merely because the browser, Companion or tunnel is temporarily unavailable.
- Recorded-session “Open chat” now routes the exact stored conversation through Eve's dedicated browser profile instead of a generic/default browser. The main process re-resolves the stored conversation id and the browser-recovery IPC remains restricted to the current live ParadigmEve renderer.
- Healthy Companion traffic periodically republishes browser presence so a renderer replaced during an update can self-heal a missed reconnect edge instead of remaining falsely disconnected.
- Focused regression coverage now exercises fresh-install routing, onboarding durability, exact browser ownership, final-tab recovery, repeated recovery clicks, renderer authority, exact-session routing and ambiguous tab-census failures.

### Downloads

- `ParadigmEve-Setup-x64.exe` — Windows x64
- `ParadigmEve-Setup-arm64.exe` — Windows on Arm
- `ParadigmEve-macOS-x64.dmg` · `ParadigmEve-macOS-x64.zip` — macOS Intel
- `ParadigmEve-macOS-arm64.dmg` · `ParadigmEve-macOS-arm64.zip` — macOS Apple silicon
- `ParadigmEve-Linux-x64.AppImage` · `ParadigmEve-Linux-x64.deb` — Linux x64
- `ParadigmEve-Linux-arm64.AppImage` · `ParadigmEve-Linux-arm64.deb` — Linux ARM64
- `ParadigmEve-Extension.zip` — standalone companion extension
- `ParadigmEve-Native-Sources.tar.gz` — native source archive, dependencies, notices and build/replacement instructions
- `SHA256SUMS.txt` — SHA-256 checksums

The native source download accompanies packaged builds and is covered by the release checksums. Installed legal notices retain the upstream Chat On Steroids contributor copyright and third-party license texts required by the bundled code.

> **macOS:** publisher-unsigned and unnotarized; verify the checksum. Requires macOS 13 Ventura or newer. Ad-hoc sealing provides bundle integrity, not publisher trust.
> **Linux:** prefer the DEB on Debian/Ubuntu. Where unprivileged user namespaces are disabled, the AppImage launcher can fall back to `--no-sandbox`.

This branch is intended for private/local distribution. Do not publish it through the upstream public release workflow.

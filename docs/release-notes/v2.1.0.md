## ParadigmEve private dogfood build

## 2.1.0

- The 22-minute cross-chat review heartbeat now uses a durable debt/completion transaction. A review obligation is saved before browser attention is queued and remains owed across restart or an explicit user message that supersedes the unclaimed transport.
- Review completion requires the exact ordinary coordinator to call `chat_review_complete` with the heartbeat's opaque key after it has finished inspecting, carrying out any still-valid bounded work, and verifying the result. Browser delivery, send ACK, assistant final prose, inactivity and sidebar state do not advance the review cursor.
- Exact coordinator/session/conversation provenance is retained across same-session Compact & Resume and bounded terminal-stall recovery. Wrong keys, worker/helper callers, blocked or ambiguous ownership, and nested code-mode calls fail closed.
- Added a private Mac-from-USB build path and Setup-time macOS Screen Recording/Accessibility controls for dogfooding the native Desktop connector on a separate Mac.
- Quilt's initial product model is now a checkerboard of durable snapshots: each pinned useful moment keeps traceable source context, what matters now, and one small next step. The three 22-minute discovery rides are aligned to that model.

The native source download accompanies packaged builds and is covered by the release checksums. Installed legal notices retain the upstream Chat On Steroids contributor copyright and third-party license texts required by the bundled code.

> **macOS:** publisher-unsigned and unnotarized; verify the checksum. Requires macOS 13 Ventura or newer. Ad-hoc sealing provides bundle integrity, not publisher trust.
> **Linux:** prefer the DEB on Debian/Ubuntu. Where unprivileged user namespaces are disabled, the AppImage launcher can fall back to `--no-sandbox`.

This branch is intended for private/local dogfooding. Do not publish it through the upstream public release workflow.

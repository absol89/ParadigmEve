# ParadigmEve 2.2.8 — Steadier recovery, Pins prompts from Eve

## 2.2.8

2.2.8 is cumulative over 2.2.7 and keeps bridge protocol **15**. It is published by the GitHub workflow
as a **debug pre-release**; promoting it to Latest is what offers it to 2.2.6 and 2.2.7 installations.

### Fixed

- **Overlapping or cut-off messages.** On ChatGPT's per-exchange renderer the Companion mounted its
  activity stream before the exchange ChatGPT measures, so later messages were drawn over earlier ones
  and a reply's end could hide behind the composer. The stream now mounts inside the measured exchange.
- **Restart wake without window focus.** Restart recovery opened Eve's exact chat by typing into the Eve
  Browser address bar, which Windows refuses while another app has focus, so the queued wake never
  posted. When focus is refused, recovery now hands the exact chat URL to the running Eve Browser profile,
  and opens nothing when the Companion already reports that chat open.
- **Browser journal loss during an outage.** While the app was unreachable, a streaming answer journalled a
  full snapshot per revision and could evict real messages from the 4 MB browser journal. The journal now
  keeps only the newest unsent snapshot of each message, as the page queue already did.
- **"Plan catalog limit reached".** The Plans catalog held 500 Plans, archived history included, and filled
  after two weeks of heavy use, after which every chat's `update_plan` was refused. It now holds 5,000.
  Archived Plans are never removed automatically, and the catalog, Plan review and chat review heartbeat
  share that one bound.
- **Fewer stuck chats (from chat-on-steroids 2.1.16).**
  - A large Project chat gets 60 seconds to load before Compact & Resume's one native click into its Project,
    instead of sharing a 12-second budget with the transition (#457).
  - When ChatGPT replaces the composer right after the model is selected, a new worker's or resumed chat's
    first message waits for the new composer instead of failing with `composer_missing` (#470).
  - Goal recognises ChatGPT's current Temporary Chat icon and its reworded introduction dialog (#472).
  - The same stream request reported twice in one attribution batch counts once instead of rejecting the
    batch, so the chat stays linked (#464).
  - An automatic Compact & Resume ticket that has not reached Send after five pickups is retried in two
    slower bursts, ten minutes apart, before it is abandoned (#391).
  - Already covered or not applicable here: #408 (ParadigmEve retires an unconfirmed send after 45 seconds),
    #462 (ParadigmEve's own per-exchange layout support) and #389 (upstream's automatic-Continue path).
    Worker ceiling parking (#390) and early worker correlation (#474) are planned separately.
- The chat review heartbeat warning for a closed saved identity now says the chat's tab is closed and to
  point the identity at Eve's current chat, instead of calling the chat ended.

### Added

- **Cancel plan.** Archive-as-finished needs every item checked, so clearing away a Plan that stopped mattering
  meant ticking items that were never done. A Live Plan now has **Cancel plan** (a second click confirms). It
  moves to Done marked **Cancelled**, keeps its checklist and progress as they were, and is as immutable as any
  archived Plan.
- **Pins prompts and Hearts over MCP.** The `pins` tool can create a Thread with its user-approved standing
  prompt (a zero-Pin Hotlink in one write), set or clear one exact Thread's prompt, and set or clear the
  Heart on one exact Prompt, Message or Plan Pin, all through the same state owner as the app's editor.
- **`%claude` starter Hotlink** in `#Eve` for Eve ↔ Claude development coordination, shipped alongside the
  other starters. An existing same-name Thread is adopted, and its prompt stays the user's.

### Cross-platform release contract

The public workflow still targets Windows x64/arm64, macOS x64/arm64, and Linux x64/arm64. macOS 13
Ventura or newer is the supported floor. Current macOS artifacts are **unsigned** and
**unnotarized** development/release-build outputs unless a later publishing process explicitly
establishes signing and notarization.

Linux keeps the documented static sandbox fallback for hosts where unprivileged user namespaces are
unavailable. The explicit `--no-sandbox` escape hatch is a last-resort compatibility path for those
hosts, not the default launch mode.

Published builds are the **debug** flavor for now, and every release is created as a GitHub
pre-release. The reviewed public workflow artifact names are:

- `ParadigmEve-Setup-x64-debug.exe`
- `ParadigmEve-Setup-arm64-debug.exe`
- `ParadigmEve-macOS-x64-debug.dmg`
- `ParadigmEve-macOS-x64-debug.zip`
- `ParadigmEve-macOS-arm64-debug.dmg`
- `ParadigmEve-macOS-arm64-debug.zip`
- `ParadigmEve-Linux-x64-debug.AppImage`
- `ParadigmEve-Linux-x64-debug.deb`
- `ParadigmEve-Linux-arm64-debug.AppImage`
- `ParadigmEve-Linux-arm64-debug.deb`
- `ParadigmEve-Extension.zip`
- `ParadigmEve-Native-Sources.tar.gz`

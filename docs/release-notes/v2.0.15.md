## ParadigmEve private build

## 2.0.15

- Dedicated ParadigmEve Chrome now starts on Windows with renderer, timer and native-window-occlusion backgrounding disabled, so turning the monitor off does not freeze the ChatGPT renderer that unattended work depends on. These switches apply only to the isolated ParadigmEve profile and do not enable remote debugging or provider-page automation.
- Companion update recovery now protects an exact ChatGPT tab from discarding and requests one bounded browser-native reload when neither the old recorder nor deterministic script reinjection can run. A fresh Chrome-issued document registration clears the latch; repeated maintenance passes cannot create a reload loop or duplicate chat tab.
- The screen-off diagnosis was verified against the local Windows power plan: AC system sleep is disabled while the display powers off after three minutes, isolating the observed overnight failure to browser/display-idle behavior rather than machine suspension.
- The existing 2.0.13/2.0.14 recovery contract remains unchanged: reinstall success still requires a current-generation Companion document, not merely a running Chrome process or updated files on disk.

- `SHA256SUMS.txt` — SHA-256 checksums

The native source download accompanies packaged builds and is covered by the release checksums. Installed legal notices retain the upstream Chat On Steroids contributor copyright and third-party license texts required by the bundled code.

> **macOS:** publisher-unsigned and unnotarized; verify the checksum. Requires macOS 13 Ventura or newer. Ad-hoc sealing provides bundle integrity, not publisher trust.
> **Linux:** prefer the DEB on Debian/Ubuntu. Where unprivileged user namespaces are disabled, the AppImage launcher can fall back to `--no-sandbox`.

This branch is intended for private/local distribution. Do not publish it through the upstream public release workflow.

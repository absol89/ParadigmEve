# ParadigmEve 2.3.8 — c1 local dogfood

Development checkpoint on release/2.3.8, not a published stable release.

- Adds the Phase-0 candidate-evaluation experiment harness under scripts/candidate-eval; it is internal and not exposed as a normal user feature.
- Includes a provisional Chrome Companion DIL fallback capture fix for repeated identical same-message references.
- Phase-0 showed no cost/quality benefit from three competing strategies on small known bug fixes; default remains one worker.
- Candidate isolation is observational, not OS-enforced. Do not run candidate experiments unsupervised.

Ported from Chat On Steroids 2.1.34:

- Compact & Resume from a chat inside a ChatGPT Project works again: the Project link is found without its old icon or header, the entry no longer needs a new editor element, a click ChatGPT's own route rewrite drops is repeated (at most twice), a handoff click that never reached ChatGPT may be sent once more, an earlier attempt's leftover request no longer blocks the next one, and a failed entry's helper tab closes.
- Goal and Loop follow-ups work on ChatGPT plans without a model picker (such as Free): the helper uses ChatGPT's current model there.
- The Background chats window is reused after the extension updates or reloads instead of opening another.
- A JavaScript `exec` script that calls a tool this connector does not offer gets a note naming the connector that has it (or saying it is not enabled), and a warning when connectors share a Secure Tunnel ID.
- `exec_command` notes when the same command is still running from earlier in the chat, and its notes plus the app's own appended context (queued messages, reports, background output) now also reach the model through the structured result.

Dogfood checks: installer launches, Companion pairs, ordinary and rich GPT-6 answers survive recording, archive and replay, existing sessions persist, and experimental harness remains inert unless explicitly invoked.

No public release, tag, merge or deployment is implied by c1.

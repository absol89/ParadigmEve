# ParadigmEve 2.3.6 — Ollama support and a more resilient Eve

ParadigmEve 2.3.6 adds first-class **Ollama** support alongside ChatGPT.

Eve can now answer a chat turn through a local Ollama model, keep that reply in the same ParadigmEve conversation and archive, and switch between ChatGPT and Ollama while preserving the useful conversation history. Local Ollama chats can also use Eve's approved local tools, so useful work does not have to stop just because a hosted model is unavailable or rate-limited.

This matters more as ChatGPT's chat, Work, model selection and usage limits continue to evolve and converge. ParadigmEve should not depend on one hosted chat surface remaining unchanged forever. Ollama gives Eve a second execution path that the user controls, including fully local models for work that should stay on the computer.

2.3.6 also improves provider switching, attachment/history handoff, delayed-response attribution, ChatGPT Voice recording, turn completion and browser delivery reliability.

### Ollama without ChatGPT setup

You can use Eve's desktop chat with a local Ollama model **without completing the ChatGPT connector, tunnel or Companion setup**. Configure Ollama and choose an Ollama model in the chat model picker; Ollama turns are delivered locally and do not wait for the ChatGPT connection.

Fresh installs still open the Setup screen until the ChatGPT onboarding flow has been completed, so for an Ollama-only install you currently need to return to Chat manually after launch. Features whose owner still runs in ChatGPT — including the full Prime/ChatGPT orchestration path and ChatGPT browser handoff features — still require the ChatGPT side of setup.

Ollama Cloud models are not local-only: use an on-device Ollama model when you want the conversation to stay on this computer.

## ParadigmEve private build

## 2.0.16

- Automatic Compact & Resume now protects long coding turns from the observed roughly-hour per-response ceiling independently of token pressure. A still-running eligible non-Pro turn gets one durable handoff ticket at 45 minutes from its original turn start, leaving time for the existing stop/tool-settle and continuation transaction to complete.
- One exact app-side deadline timer owns this protection across all live chats; normal tool activity cannot push the deadline later. The timer follows exact durable session, conversation and turn authority and is cancelled or re-armed on completion, new turns, Pro/Astra model changes, Automatic Compact Off/On, Block/Release, worker binding, compaction/rebind and bridge stop/start.
- Existing safety semantics remain intact: Automatic Compact Off, Pro/Astra, worker chats, blocked chats, refused turns, superseded conversations and existing continuations all fence the age trigger. A Block that races an already-filed automatic handoff now also fences source/destination send actions before they can cross the handoff boundary.
- Fake-time and integration coverage exercises the 45-minute edge without changing production timing, including just-before/at-deadline behavior, exactly-once filing, completed turns, blocked/worker/Pro chats, Pro→Sol, Auto Off→On and restart/reattach recovery.
- ParadigmEve now carries explicit reboot memory in both the project `AGENTS.md` and an app-owned `RECOVERY.md` under userData. When restart state proves an unfinished ordinary chat with local tool work, startup queues one deterministic recovery instruction for that exact session/conversation/turn before browser recovery is allowed to proceed.
- Restart recovery is deliberately queue-first and not stop-first. The startup path never presses Stop merely to make room for its recovery message; if the durable enqueue fails or identity is ambiguous, the existing turn is left running. Repeated restarts reuse the same outbox identity, and Companion update recovery leaves `chrome://extensions/` after maintenance and returns to the exact owed ChatGPT conversation when known.

The native source download accompanies packaged builds and is covered by the release checksums. Installed legal notices retain the upstream Chat On Steroids contributor copyright and third-party license texts required by the bundled code.

> **macOS:** publisher-unsigned and unnotarized; verify the checksum. Requires macOS 13 Ventura or newer. Ad-hoc sealing provides bundle integrity, not publisher trust.
> **Linux:** prefer the DEB on Debian/Ubuntu. Where unprivileged user namespaces are disabled, the AppImage launcher can fall back to `--no-sandbox`.

This branch is intended for private/local distribution. Do not publish it through the upstream public release workflow.

## ParadigmEve private dogfood release candidate

## 2.1.3

This file describes the current **2.1.3 candidate source/test scope**. It does not claim that a 2.1.3 installer has been packaged, installed or live-accepted yet; those remain separate release gates.

- **Expenses stays local and structured.** The candidate includes a recurring Expenses project/inbox, structured local ledger intake for text and receipts, optional raw-receipt retention only when chosen, exact correction provenance, monthly budget buckets and per-item overrides. Receipt merchant/location evidence stays separate from monthly budget classification.
- **Bank evidence can reconcile without double counting.** New shared reconciliation primitives keep bank transactions and receipts as separate evidence objects, score likely matches without fuzzy auto-confirmation, preserve confirmed/rejected audit links, and suppress a confirmed receipt duplicate only in derived reconciliation totals. The comparison helpers can also measure reconstructed monthly totals against a human-curated reference ledger and expose bank-only or receipt-only evidence gaps.
- **Recovery work preserves browser/session ownership.** The candidate contains the current Chrome native-restore/reuse path plus related exact-session, worker/Prime and startup/readiness regression work. This note intentionally does not claim a completed 2.1.3 reinstall rehearsal.
- **Current desktop/product integration is included in the candidate tree.** Swedish/US-English interface work, workspace/Pins/Plans navigation, startup presentation and build-flavor/provider policy are represented in source and focused regression coverage. Final package/runtime behavior still requires the coordinated release gate.

### Expected release artifacts

Canonical shipping target names for a completed 2.1.3 release remain:

- `ParadigmEve-Setup-x64.exe` — Windows x64
- `ParadigmEve-Setup-arm64.exe` — Windows on Arm
- `ParadigmEve-macOS-x64.dmg` · `ParadigmEve-macOS-x64.zip` — macOS Intel
- `ParadigmEve-macOS-arm64.dmg` · `ParadigmEve-macOS-arm64.zip` — macOS Apple silicon
- `ParadigmEve-Linux-x64.AppImage` · `ParadigmEve-Linux-x64.deb` — Linux x64
- `ParadigmEve-Linux-arm64.AppImage` · `ParadigmEve-Linux-arm64.deb` — Linux ARM64
- `ParadigmEve-Extension.zip` — standalone companion extension
- `ParadigmEve-Native-Sources.tar.gz` — native source archive, dependencies, notices and build/replacement instructions
- `SHA256SUMS.txt` — SHA-256 checksums

No 2.1.3 artifact hash is recorded here until that exact artifact is built and verified.

> **macOS:** publisher-unsigned and unnotarized; verify the checksum once artifacts exist. Requires macOS 13 Ventura or newer. Ad-hoc sealing provides bundle integrity, not publisher trust.
> **Linux:** prefer the DEB on Debian/Ubuntu. Where unprivileged user namespaces are disabled, the AppImage launcher can fall back to `--no-sandbox`.

This candidate is prepared for private/local dogfooding. Do not publish it through the upstream public release workflow until the privacy/history, full verification, packaging, native smoke and live acceptance gates have all been resolved.

# ParadigmEve private dogfood release candidate

## 2.1.7

LAN-identity and heartbeat-budget Windows debug candidate.

## What changed

- Semantic cross-chat review keeps the intended **22-minute** model-turn cadence. A missing or rejected completion receipt no longer turns the one-minute local retry loop into repeated ChatGPT turns for the same heartbeat epoch.
- Each debug installation gets a long-lived cryptographic LAN identity generated by ParadigmEve rather than from a MAC address, motherboard id, Windows machine id, IP address or hostname. Its private material stays in the OS-protected ParadigmEve secret store.
- Ordinary ParadigmEve updates and reinstall-over-the-same-install preserve that identity because the installer preserves userData and the identity is generated only when a valid stored identity does not already exist. Manually deleting ParadigmEve userData/secrets, explicitly resetting all app secrets, or reinstalling the OS can create a new identity.
- LAN nicknames are reserved against that installation fingerprint within a joined group. `Eva` and `eva` are the same reservation, Unicode-equivalent spellings normalize to the same name, and invisible formatting controls are rejected at the LAN identity boundary.
- This remains a decentralized debug LAN lab. A peer that has never seen a reservation cannot infer an offline claim across a network partition; when independently-created conflicting claims later meet, ParadigmEve fails closed instead of silently picking one. Direct agent-to-agent messaging and VPN endpoint routing remain future layers.

### Expected release artifacts

Canonical shipping target names for a completed 2.1.7 release remain:

- `ParadigmEve-Setup-x64.exe` — Windows x64
- `ParadigmEve-Setup-arm64.exe` — Windows on Arm
- `ParadigmEve-macOS-x64.dmg` · `ParadigmEve-macOS-x64.zip` — macOS Intel
- `ParadigmEve-macOS-arm64.dmg` · `ParadigmEve-macOS-arm64.zip` — macOS Apple silicon
- `ParadigmEve-Linux-x64.AppImage` · `ParadigmEve-Linux-x64.deb` — Linux x64
- `ParadigmEve-Linux-arm64.AppImage` · `ParadigmEve-Linux-arm64.deb` — Linux ARM64
- `ParadigmEve-Extension.zip` — standalone companion extension
- `ParadigmEve-Native-Sources.tar.gz` — native source archive, dependencies, notices and build/replacement instructions
- `SHA256SUMS.txt` — SHA-256 checksums

> **macOS:** publisher-unsigned and unnotarized; verify the checksum once artifacts exist. Requires macOS 13 Ventura or newer. Ad-hoc sealing provides bundle integrity, not publisher trust.
> **Linux:** prefer the DEB on Debian/Ubuntu. Where unprivileged user namespaces are disabled, the AppImage launcher can fall back to `--no-sandbox`.

## Dogfood target

Build the Windows x64 **`-debug`** installer from the reviewed dirty tree, install it over Eve first, confirm the installed app still owns the same local settings/session data, then update Eva and verify both installations retain stable fingerprints across a subsequent reinstall/update cycle.

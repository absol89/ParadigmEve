## ParadigmEve private build

## 2.0.19

- Eve now has a durable 22-minute semantic review heartbeat for the always-on laptop. It wakes one exact proven Eve coordinator to look for still-valid work that was requested in ChatGPT but never actually carried out because the conversation stopped at prose, a plan or a promise.
- Review begins with exact locally recorded sessions and message identity. When a phone/app/web conversation never reached the laptop recorder, Eve may inspect the signed-in ChatGPT web history with Computer Use before deciding whether anything remains owed.
- The heartbeat is deliberately conservative: it is browser-only, idempotent, coalesces with other internal review attention, never treats blue dots or inactivity as completion evidence, fails closed on ambiguous ownership and yields to explicit user instructions or work that is already running/completed.
- Added a `work_context` Core tool and matching executor guidance so ChatGPT can check the connected ParadigmEve computer, live permissions and caller identity before saying it cannot save files, implement changes, use Computer Use or contact workers. When execution is requested, a draft or promise is not treated as the saved result.
- Added the first three 22-minute Quilt discovery rides plus the product-direction docs that frame Quilt as Eve's continuity layer: preserve useful moments with traceable context, make a small useful result visible quickly, and reduce mental load rather than creating another system to maintain.
- Eve Browser closure/recovery continues to use the Companion's exact native ChatGPT-tab census so closing the final ChatGPT tab does not get confused with a still-warm presence heartbeat or create duplicate recovery tabs.

- `SHA256SUMS.txt` — SHA-256 checksums

The native source download accompanies packaged builds and is covered by the release checksums. Installed legal notices retain the upstream Chat On Steroids contributor copyright and third-party license texts required by the bundled code.

> **macOS:** publisher-unsigned and unnotarized; verify the checksum. Requires macOS 13 Ventura or newer. Ad-hoc sealing provides bundle integrity, not publisher trust.
> **Linux:** prefer the DEB on Debian/Ubuntu. Where unprivileged user namespaces are disabled, the AppImage launcher can fall back to `--no-sandbox`.

This branch is intended for private/local distribution. Do not publish it through the upstream public release workflow.

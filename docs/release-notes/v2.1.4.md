# ParadigmEve private dogfood release candidate

## 2.1.4

Private Windows dogfood recovery candidate.

## Why this supersedes 2.1.3

The 2.1.3 debug installer itself completed successfully, but its post-install recovery path was not accepted: recovery could depend exclusively on Chrome's native `Restore pages?` affordance, and if that bounded UIA lookup missed the affordance ParadigmEve could leave the installation's owning agent disconnected and idle until a later wake mechanism.

2.1.4 restores the stronger fail-closed synthesis:

- restored swarm/session ownership must prove one exact owning-agent conversation;
- that exact owning-agent URL is reopened immediately inside ParadigmEve's dedicated Chrome profile, never the user's ordinary Chrome profile;
- one durable owning-agent restart wake is queued immediately, so coordination can resume without waiting for the periodic semantic heartbeat;
- Chrome's native `Restore pages?` → `Restore` action is still checked and invoked when genuinely offered, preserving the rest of the previous dedicated-profile session;
- a generic window-frame control named `Restore` is never sufficient evidence;
- ambiguous owning-agent identity, duplicate local ownership, malformed recovery URLs and stale turn metadata fail closed rather than guessing from recency, titles or visible tabs.

Bridge protocol remains **14** because this recovery correction does not change the app/Companion wire contract.

### Expected release artifacts

Canonical shipping target names for a completed 2.1.4 release remain:

- `ParadigmEve-Setup-x64.exe` — Windows x64
- `ParadigmEve-Setup-arm64.exe` — Windows on Arm
- `ParadigmEve-macOS-x64.dmg` · `ParadigmEve-macOS-x64.zip` — macOS Intel
- `ParadigmEve-macOS-arm64.dmg` · `ParadigmEve-macOS-arm64.zip` — macOS Apple silicon
- `ParadigmEve-Linux-x64.AppImage` · `ParadigmEve-Linux-x64.deb` — Linux x64
- `ParadigmEve-Linux-arm64.AppImage` · `ParadigmEve-Linux-arm64.deb` — Linux ARM64
- `ParadigmEve-Extension.zip` — standalone companion extension
- `ParadigmEve-Native-Sources.tar.gz` — native source archive, dependencies, notices and build/replacement instructions
- `SHA256SUMS.txt` — SHA-256 checksums

No 2.1.4 artifact hash is recorded here until that exact artifact is built and verified.

> **macOS:** publisher-unsigned and unnotarized; verify the checksum once artifacts exist. Requires macOS 13 Ventura or newer. Ad-hoc sealing provides bundle integrity, not publisher trust.
> **Linux:** prefer the DEB on Debian/Ubuntu. Where unprivileged user namespaces are disabled, the AppImage launcher can fall back to `--no-sandbox`.

## Release gates

The source-level recovery patch has focused regression coverage, but this note does not claim live acceptance yet. Before 2.1.4 is accepted for dogfood, the settled tree must pass the release gates, a fresh 2.1.4 x64 debug installer must be built and hashed, and the real self-reinstall rehearsal must prove that the exact owning agent wakes immediately while the prior dedicated Chrome session is preserved/restored.

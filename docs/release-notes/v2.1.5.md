# ParadigmEve private dogfood release candidate

## 2.1.5

Private Windows dogfood candidate for one-agent identity, exact recovery and semantic-heartbeat verification.

## What changed

- The human-facing owner is now the installation's configured agent name (`Eve`, `Eva`, etc.), not a separate Prime/Sol/Gaia persona. Exactly one durable owner conversation may hold that identity, or ownership is null and **New Chat** carries the agent sticker instead.
- A fresh New Chat becomes the owning agent only after ChatGPT's exact send acknowledgement proves the provider conversation id. Titles, recency, visible tabs and historical worker-family state are never ownership authority.
- Compact & Resume transfers the same durable agent identity through the existing exact continuation transaction. Deleting the exact owner clears ownership rather than promoting a historical chat.
- Restart/reinstall recovery consumes only that exact durable agent identity, queues one immediate owner wake, and keeps Chrome's native previous-session restore additive for the rest of the dedicated-profile tabs.
- The semantic heartbeat now transfers pending review debt away from canonically failed coordinators with no active turn, while its authenticated completion receipt records bounded result state without exposing authored Plan/chat content.
- Bridge protocol remains **14** because these changes do not alter the app/Companion wire contract.

### Expected release artifacts

Canonical shipping target names for a completed 2.1.5 release remain:

- `ParadigmEve-Setup-x64.exe` — Windows x64
- `ParadigmEve-Setup-arm64.exe` — Windows on Arm
- `ParadigmEve-macOS-x64.dmg` · `ParadigmEve-macOS-x64.zip` — macOS Intel
- `ParadigmEve-macOS-arm64.dmg` · `ParadigmEve-macOS-arm64.zip` — macOS Apple silicon
- `ParadigmEve-Linux-x64.AppImage` · `ParadigmEve-Linux-x64.deb` — Linux x64
- `ParadigmEve-Linux-arm64.AppImage` · `ParadigmEve-Linux-arm64.deb` — Linux ARM64
- `ParadigmEve-Extension.zip` — standalone companion extension
- `ParadigmEve-Native-Sources.tar.gz` — native source archive, dependencies, notices and build/replacement instructions
- `SHA256SUMS.txt` — SHA-256 checksums

No 2.1.5 artifact hash is recorded here until that exact artifact is built and verified.

> **macOS:** publisher-unsigned and unnotarized; verify the checksum once artifacts exist. Requires macOS 13 Ventura or newer. Ad-hoc sealing provides bundle integrity, not publisher trust.
> **Linux:** prefer the DEB on Debian/Ubuntu. Where unprivileged user namespaces are disabled, the AppImage launcher can fall back to `--no-sandbox`.

## Dogfood acceptance gates

Source/tests are not live acceptance. The Windows x64 debug candidate still has to be built and installed over the running dogfood app, then prove the exact Eve/Eva conversation restores and self-wakes without duplicate owner tabs. LAN acceptance additionally requires two explicit same-key opt-ins on the same local network and a live peer observation in both directions. The semantic-heartbeat acceptance requires a real heartbeat turn to find and dispatch intentionally actionable unfinished Plan work, followed by its authenticated completion receipt.

## ParadigmEve private build

## 2.0.17

- Worker completion now follows ChatGPT's canonical successful final-assistant metadata instead of sidebar unread dots, quiet time, streaming text or in-progress tool calls. Stable worker finals are durably reconciled across event batches and can wake Prime for one coalesced review turn without interrupting Prime's live tool sequence.
- Completed workers remain sleeping, writable and reusable. Prime can send bounded follow-up work through `agents action=message` and revive the exact retained worker conversation instead of spawning a replacement or treating the worker as a read-only archive.
- Prime review attention is durable, browser-only, replay-idempotent and subordinate to real user input. It waits behind an active Prime turn, survives a temporarily absent Companion, stays out of the editable human outbox, and fails closed rather than guessing when Prime session ownership is ambiguous.
- App-authored sends now keep the exact elected ChatGPT page render-capable before delivery. The dedicated ParadigmEve Chrome profile also applies one shared aggressive background-processing policy on Windows, disabling renderer/timer/occluded-window backgrounding plus native occlusion and intensive wake-up throttling without remote debugging or provider-page automation.
- Restart and guided-setup recovery are harder to strand: extension maintenance returns to the exact owed ChatGPT conversation, completed chats no longer resurrect from stale activity, setup preflight is single-flight and abortable, and restart recovery remains durable-outbox-first without treating a persisted turn id as live Stop authority.
- Renderer IPC now fails closed unless the sender is the current live ParadigmEve BrowserWindow webContents, including plugin IPC routed through the shared wrapper. Worker lifecycle UI/diagnostics also follow broker truth so sleeping workers release active slots without becoming terminal.
- Public-focus-test coverage now exercises fresh install, setup/recovery, app-composer browser liveness, renderer authority, worker lifecycle, canonical-final Prime attention and dedicated-browser maintenance.

The native source download accompanies packaged builds and is covered by the release checksums. Installed legal notices retain the upstream Chat On Steroids contributor copyright and third-party license texts required by the bundled code.

> **macOS:** publisher-unsigned and unnotarized; verify the checksum. Requires macOS 13 Ventura or newer. Ad-hoc sealing provides bundle integrity, not publisher trust.
> **Linux:** prefer the DEB on Debian/Ubuntu. Where unprivileged user namespaces are disabled, the AppImage launcher can fall back to `--no-sandbox`.

This branch is intended for private/local distribution. Do not publish it through the upstream public release workflow.

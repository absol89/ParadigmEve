# Capability audit — demonstrate, do not advertise

**Give the contestant only this task (substitute its own approved disposable fixture path):**

> Audit your capabilities in this exact chat and account, not a marketing feature list. Demonstrate one real permitted local file read and one actual test or shell run against `<path>` if such tools are available. Record the tool's identity, outcome and a short evidence excerpt. Then say whether you can read prior-chat context, create persistent references and work across a new conversation. Separate demonstrated facts from claims and unavailable features. Do not change settings, attempt permission bypass or access private files.

Participants without computer or shell tools must state that limitation, not invent a receipt. Scoring only awards demonstrated tools; product feature parity belongs in a separate qualitative table and is not implied by a model name.

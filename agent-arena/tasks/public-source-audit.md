# Public-source research: two current claims

**Give the contestant only this task:**

> Using public primary-source documentation that you actually retrieve, determine whether a public open-source GitHub project can host a static agent benchmark and documentation on GitHub Pages for free. Check its limitations and whether GitHub Pages itself can execute arbitrary agent tasks. Also check whether standard GitHub-hosted Actions runners for public repositories incur a per-minute charge. Cite at least two official sources and distinguish the site hosting from any third-party model/API or human-review costs. Give the retrieval date and label anything you could not verify.

This question deliberately requires source discipline and current verification. The evaluator checks **what the sources said on the run date**; there is no permanent answer string. Never award retrieval credit for an unvisited remembered URL.

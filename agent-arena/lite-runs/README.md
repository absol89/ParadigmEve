# Lite reviewed submissions

Each file named `<run-id>.json` (excluding the template) holds a **reviewer's accepted criterion checks**, not an automated claim of model intelligence. Participants may provide only a Markdown report in any writable location. The reviewer transcribes supported checks into the versioned template.

Use `node agent-arena/tools/build-lite-results.mjs` only as the maintainer, after manual review. Self-reports are excluded. No raw private transcripts, user data or credentials belong in a public JSON file.

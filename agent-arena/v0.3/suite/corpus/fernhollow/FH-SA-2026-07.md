# Security advisory FH-SA-2026-07: acknowledged messages redelivered after a broker restart

- ID: FH-SA-2026-07
- Publisher: Fernhollow project (official security advisories)
- Published: 2026-11-30

**Affected versions:** 5.2.0 through 5.4.0.
**Fixed in:** 5.4.1.
**Workaround:** set `ack.sync: true`.

# Configuration reference

- ID: FH-DOC-CONFIG
- Publisher: Fernhollow project (official documentation site)
- Last updated: 2026-05-04

| Setting | Default | Notes |
| --- | --- | --- |
| `retention.default` | 3 days | How long messages are kept when a topic sets no retention. |
| `consumer.prefetch` | 50 | Messages a consumer may hold unacknowledged. |
| `--compat-v4` | off | Accept clients that speak the v4 wire protocol. |

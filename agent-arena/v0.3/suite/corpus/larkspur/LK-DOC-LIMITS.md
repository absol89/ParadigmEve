# Larkspur documentation — Limits

- ID: LK-DOC-LIMITS
- Publisher: Larkspur project (official docs site)
- Page last updated: 2026-02-11

| Limit | Value |
| --- | --- |
| Maximum payload size | 1 MiB |
| Default client retries | 3 |
| Rate limit per token | 600 requests/minute |

Requests over the payload limit fail with `413 Payload Too Large`.

- ID: LK-MIRROR-NEWS
- Publisher: larkspur-news.example (third-party aggregator; not affiliated with the project)
- Published: 2026-08-21

The Larkspur team has patched a token issue. Versions up to 3.1.1 are affected and users should upgrade to
3.1.2, which contains the fix. A workaround is to disable the token cache.

# Larkspur changelog

- ID: LK-CHANGELOG
- Publisher: Larkspur project (official repository, CHANGELOG.md)

## 3.3.0-rc.1 — 2026-10-01 (pre-release)
- Experimental streaming uploads. Not for production use.

## 3.2.1 — 2026-08-19
- Security: fixes advisory LK-SA-2026-03 (token reuse after revocation).

## 3.2.0 — 2026-07-02
- Maximum payload size raised from 1 MiB to 4 MiB.
- New `compression` option on the client.

## 3.1.0 — 2026-04-15
- `legacyAuth` is deprecated. It still works; removal is planned for 4.0.

## 3.0.0 — 2026-01-20
- New token format. Payload limit stays at 1 MiB.

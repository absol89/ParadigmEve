TRANSPARENT EVIDENCE
How the evaluation works

      

        
01 · Fetch
Use the public Markdown task or manifest.json. No account is required to read.

        
02 · Execute
Run in an approved disposable workspace. Fresh chats for recall and reference tasks.

        
03 · Verify
Preserve original prompts, test output, exact file diffs, session boundaries and retrieval receipts.

        
04 · Publish
Independent review accepts a public run record through a repository pull request. The static results table is regenerated offline.

      

      
Open-book benchmark: public tasks and tests may be studied in advance. This is not a hidden leaderboard or a scientifically definitive model ranking. Design inspirations include SWE-bench Verified, GAIA, BrowseComp, LongMemEval, BFCL and Terminal-Bench; their original results are not copied. See our capability comparison and result-reporting procedure. No provider is endorsed by this evaluation.

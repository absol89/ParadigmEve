# Security advisory LK-SA-2026-03: revoked tokens accepted for up to 10 minutes

- ID: LK-SA-2026-03
- Publisher: Larkspur project (official security advisories)
- Published: 2026-08-19

**Affected versions:** 3.0.0 through 3.2.0.
**Fixed in:** 3.2.1.
**Workaround:** set `tokenCacheSeconds: 0` on the server.

# What's new in Fernhollow Cloud this winter

- ID: FH-BLOG-CLOUD
- Publisher: Fernhollow Cloud blog (the commercial hosted service, not the open-source project)
- Published: 2027-01-20

Every Cloud plan now keeps messages for 14 days by default, and you can pay for longer. We have also
retired `--compat-v4` across Cloud: v4 clients can no longer connect to hosted brokers.

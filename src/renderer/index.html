    Setup
    Connect your workspace to ChatGPT.
    
              
    
                
                
              
    
            
    
            
    
              
    Six steps, one configuration. ParadigmEve enables its ordinary local tools by default, including command execution. ChatGPT still controls custom-app access and may ask for approval or block higher-risk actions.
    
              
    
                
                ParadigmEve can guide the browser steps in one dedicated Eve Browser profile.
              
    
              
    
                
                Tunnel ID and API key values stay hidden by default. Keep them hidden while recording, screen sharing or streaming; reveal them only when you need to check what you pasted.
              
    
              
    
                
                
                
    Use a different name, such as Eva, to separate different computers.
    
              
    
              Click a step number to preview any step without changing your setup progress.
              
            
    

            
      
              
              
    1. 
                
                
      
                  
      Pick a folder to work in
      
                  
      
                    Nothing outside the folders you approve is reachable. Do this first — the tunnel
                    will not start with no folder set.
                  
      
                  
      
                    
                    
                    None yet

                      Screen Recording and Accessibility are required for the parts of Computer use you enabled.

      Create a tunnel

                    Eve. Pick the same workspace you use in

    3. 
                
                
      
                  
      
                    
      Create an API key
      
                  
      
                  
      
                    Create one key of type Restricted and give it only
                    Tunnels: Read and Tunnels: Use. Leave
                    everything else as None. Computer use is part of the same
                    ParadigmEve connection, so there is no second tunnel or API key.
                    Copy the key right away — the platform will not show it again.

      Start the tunnel
      
                  
      
                    Leave it running while you use the connector. It stays available when you close
                    the window.
                  
      
                  
      
                    
                    
                  
      
                
      
              
      5. 

              
              
              
    5. 
                
                
      
                  
      Add the Companion extension
      
                  
      
                    Open chrome://extensions/ in Google Chrome / Chromium, turn on Developer mode,
                    choose Load unpacked and pick the folder the button opens. Then
                    open or reload a ChatGPT tab after installation so the Companion is actually
                    present on that page. It pairs with this app by itself — there is no code to type.
                  
      
                  
      
                    Required for exact chat identity: stateful Computer use, session
                    recording and sub-agents use the live Companion to prove which ChatGPT
                    conversation issued a request. ParadigmEve does not treat an installed extension
                    as proof that this connection is working.
                  
      
                  
      
                    
                    
                    
                    
                  
      
                  
      
                
      
              
      6. 

              
              
    6. 
                
                
      
                  
      
                    
      Add it in ChatGPT
      
                  
      
                  
      
                    First turn on Developer mode in ChatGPT. Then open the connector
                    creation page and create the single Eve app shown below.
                    Computer use appears inside that same app whenever you enable its permissions in
                    ParadigmEve.
                  
      
                  
      
                    
                    
                  
      
                  
        
                    
      • 
                      On the first page, turn Developer mode on before continuing.
                      Developer mode enables the custom Eve connector; it does
                      not grant unrestricted action access by itself.
                    
        • 
                    
      • Use the exact name and description from the card — copy them, do not invent your own.
        • 
                    
      • 
                      When ChatGPT asks for an app icon, upload the included icon.png.
                      
                    
        • 
                    
      • 
                      For authentication choose No authentication.
                    
        • 
                    
      • 
                  
      
                  
                  
      
                  
      
                    Choose how much autonomy you want
                    
      
                      After saving the connector, open ChatGPT → Settings → Plugins → Eve → Permissions.
                      We recommend leaving Allow low risk actions selected.
                    
      
                    
      
                      ChatGPT can automatically approve actions it considers low risk, while higher-risk
                      actions such as commands, file changes, or computer-control actions may ask for your
                      approval or be denied. Choose Allow all actions only if you intentionally want
                      longer Goal, Loop or agent tasks to continue without those approval stops. ParadigmEve's
                      own folder and capability permissions still apply either way.
                    
      
                  
      
                  
      
                    
                  
      
                
      
              
      7. 
            
    

            
    
              
    Advanced — method, program, startup
    

              
    
                
                
                
    
              
    

              
    
                
                
    
                  
                  
                
    
                
    
              
    

              
    
                
                
                
    Startup and auto-connect are opt-in. A live tunnel uses network, but connecting alone does not call a model. Periodic review, recovery, Goal/Loop, and browser automation can use network or model turns separately when active.
    
                
                
                
    Windows Computer Use already captures the selected window and owned popups. This preference matters on desktop backends that can otherwise capture the monitor.
    
                
              
    

              
    
                
    Eve authority
    
                
                
    Lets chats using this Eve connector reach Eve even without the main Eve Browser chat. Turn this off for strict main-chat-only access.
    
                
                
    Lets Eve adjust this app's settings during maintenance or repair.
    
                
                
    Lets Eve archive completed Eve and worker Plans after every item is done. This does not delete Activity, sessions, or Threads.
    
                
                
    Off: each revision waits for your Send to orchestrator on the chat's Plan. On: the orchestrator may act on a revision as soon as it is written.
    
                
                
    Lets Eve use Computer Use inside this app. Turning this on also allows settings changes, because mouse and keyboard input cannot be separated from settings clicks.
